## 설명은 JavaScript로 진행한다

실제로 Cubase에서 실행되는 DustBox VST3는 C++로 만든다.

하지만 이 글의 목적은 C++ 문법을 배우는 것이 아니라, 새츄레이션이 숫자를 어떻게 바꾸는지 이해하는 것이다.

따라서 먼저 JavaScript로 원리를 확인한다.

```text
이 글
→ JavaScript로 새츄레이션 원리 이해

실제 플러그인 구현
→ 같은 처리 순서를 C++와 JUCE로 옮김
```

언어는 달라도 핵심 순서는 같다.

```text
샘플을 하나 받음
→ Drive를 적용
→ 비선형 함수로 값을 변경
→ 처리된 샘플을 반환
```

---

## 비선형 반응을 코드로 옮겨보자

앞에서는 새츄레이션이 입력과 출력을 같은 비율로 내보내지 않는 처리라고 설명했다.

```text
작은 입력
→ 입력과 출력의 차이가 크지 않음

큰 입력
→ 출력의 증가량이 점점 줄어듦
```

이제 이 관계를 코드로 만들어야 한다.

코드를 보기 전에 컴퓨터 안에서 소리가 어떤 상태인지부터 짚고 넘어가자.

### 컴퓨터 안의 소리는 숫자다

마이크로 들어온 소리는 컴퓨터 안에서 연속된 숫자로 저장된다.

숫자 하나를 `샘플(sample)`이라고 한다.

```text
0.02, 0.18, 0.46, 0.81, 0.43, 0.10, -0.25, -0.72 ...
```

각 숫자는 해당 순간에 파형이 어디에 있는지를 나타낸다.

일반적인 오디오 코드에서는 샘플을 대략 `-1.0`부터 `1.0` 사이의 값으로 다룬다.

```text
 1.0  파형의 위쪽 큰 지점
 0.0  가운데 지점
-1.0  파형의 아래쪽 큰 지점
```

플러그인이 해야 하는 일은 간단하다.

```text
처리 전 샘플을 하나 받음
        ↓
숫자를 새츄레이션 함수에 넣음
        ↓
변경된 숫자를 돌려줌
```

예를 들어 입력이 `0.5`라면 함수가 처리한 뒤 `0.46`을 출력할 수 있다.

입력이 `1.0`처럼 커지면 출력은 `0.76` 정도로 더 많이 눌릴 수 있다.

이 작업을 오디오에 들어 있는 모든 샘플에 반복하면 파형 전체의 모양이 달라진다.

---

## 어떤 함수를 사용해야 할까?

우리가 원하는 변화는 다음과 같다.

```text
입력이 작을 때
→ 원래 값과 크게 다르지 않음

입력이 커질 때
→ 출력 증가량이 서서히 줄어듦

입력이 아주 클 때
→ 일정한 범위에 가까워짐
```

출력을 갑자기 잘라버리는 방법도 있다.

```text
입력 0.8 → 출력 0.8
입력 1.0 → 출력 1.0
입력 1.2 → 출력 1.0
입력 2.0 → 출력 1.0
```

하지만 이 방식은 한계를 넘는 순간 파형을 평평하게 자른다. 이를 `하드 클리핑`이라고 한다.

지금 만들려는 새츄레이션은 조금 다르다.

```text
입력 0.5 → 출력 0.46
입력 0.8 → 출력 0.66
입력 1.0 → 출력 0.76
입력 2.0 → 출력 0.96
```

입력이 한계에 도달한 순간 갑자기 자르는 것이 아니라, 커질수록 조금씩 덜 증가한다.

이런 곡선을 만드는 방법 가운데 하나가 `tanh` 함수다.

`tanh`는 hyperbolic tangent의 줄임말이다. 이름보다 모양이 중요하다.

```text
출력
 1.0 |            ______
     |         __/
 0.0 |________/____________ 입력
     |      __/
-1.0 |_____/
```

가운데에서는 입력을 비교적 그대로 따라가고, 위아래로 갈수록 점점 완만해진다.

이 모양이 큰 신호가 서서히 포화되는 모습과 비슷하다.

---

## 가장 작은 새츄레이션 함수

JavaScript에서는 다음처럼 작성할 수 있다.

```js
function saturate(input, drive) {
  const driven = input * drive;
  return Math.tanh(driven);
}
```

코드는 짧지만 각 부분이 어떤 역할을 하는지 확인할 필요가 있다.

### `function saturate(input, drive)`

`saturate`라는 함수를 만든다.

이 함수는 처리할 샘플인 `input`과 새츄레이션 양을 정할 `drive`를 받는다.

### `input`

처리하기 전의 샘플 하나다.

```text
input = 0.1
input = 0.5
input = -0.8
```

오디오가 재생되는 동안 계속 다른 값이 들어온다.

### `drive`

입력을 비선형 구간으로 얼마나 강하게 밀어 넣을지 정한다.

```text
drive가 작음
→ tanh 곡선의 가운데 부분을 주로 사용
→ 변화가 비교적 약함

drive가 큼
→ 완만해지는 구간까지 빠르게 도달
→ 더 많은 부분이 눌림
```

### `driven`

입력에 Drive를 곱한 중간값이다.

```js
const driven = input * drive;
```

예를 들어 입력이 `0.5`이고 Drive가 `2.0`이라면 다음과 같다.

```text
driven = 0.5 × 2.0
       = 1.0
```

`const`는 이 함수 안에서 `driven` 값을 다시 바꾸지 않겠다는 뜻이다.

### `Math.tanh(driven)`

Drive가 적용된 값을 `tanh` 곡선에 넣는다.

결과가 함수의 출력 샘플이 된다.

```js
return Math.tanh(driven);
```

`Math`는 JavaScript가 기본으로 제공하는 수학 기능을 모아둔 객체다.

## 실제 숫자를 넣어보자

Drive를 `1.0`으로 두면 다음과 같은 결과가 나온다.

| 입력 | 출력 | 변화 |
|---:|---:|---|
| 0.1 | 0.0997 | 거의 그대로 |
| 0.5 | 0.4621 | 조금 눌림 |
| 0.8 | 0.6640 | 더 많이 눌림 |
| 1.0 | 0.7616 | 큰 부분이 완만하게 제한됨 |

입력이 커질수록 입력과 출력의 차이도 커진다.

```text
입력 0.1
→ 출력 0.0997
→ 차이가 거의 없음

입력 1.0
→ 출력 0.7616
→ 큰 부분이 눈에 띄게 눌림
```

음수도 같은 방식으로 처리된다.

```text
입력  0.8 → 출력  0.6640
입력 -0.8 → 출력 -0.6640
```

파형의 위쪽과 아래쪽을 대칭으로 누르는 형태다.

---

## Drive를 높이면 무엇이 달라질까?

Drive를 `2.0`으로 올려보자.

| 입력 | Drive 적용값 | tanh 출력 |
|---:|---:|---:|
| 0.1 | 0.2 | 0.1974 |
| 0.5 | 1.0 | 0.7616 |
| 0.8 | 1.6 | 0.9217 |
| 1.0 | 2.0 | 0.9640 |

여기서 한 가지 이상한 점이 보인다.

Drive를 높였더니 출력이 이전보다 커졌다.

```text
Drive 1.0
입력 0.5 → 출력 0.4621

Drive 2.0
입력 0.5 → 출력 0.7616
```

Drive는 새츄레이션의 양만 바꾸는 값이 아니다. 함수에 들어가기 전의 입력 크기도 함께 키운다.

따라서 Drive를 높이면 다음 두 변화가 동시에 발생한다.

```text
입력이 커짐
        +
파형이 더 많이 눌림
```

이 상태에서 처리 전후를 바로 비교하면 단순히 소리가 커져서 더 좋아졌다고 느낄 수 있다.

그래서 실제 플러그인에는 새츄레이션 뒤의 음량을 줄이는 `Output` 또는 자동 음량 보정이 필요하다.

```text
입력
  ↓
Drive로 키움
  ↓
tanh로 파형을 누름
  ↓
Output으로 최종 음량을 맞춤
```

## 이 코드가 실제 테이프를 그대로 재현하는 것은 아니다

`tanh` 곡선은 큰 신호를 부드럽게 누르는 가장 단순한 출발점이다.

실제 진공관, 테이프와 트랜스포머는 입력 크기만 보지 않는다.

```text
주파수에 따른 반응
이전 신호의 영향
좌우가 다른 비대칭 왜곡
장비의 노이즈
헤드와 회로의 특성
```

여러 조건이 함께 작동한다.

따라서 다음 코드를 `실제 아날로그 장비의 완전한 모델`이라고 부르면 안 된다.

```js
return Math.tanh(input * drive);
```

현재 단계에서 이 함수의 목적은 하나다.

```text
입력이 커질수록
출력이 같은 비율로 증가하지 않는
가장 단순한 새츄레이션 만들기
```

다음 단계에서는 이 함수를 샘플 하나가 아니라 JavaScript 배열에 담긴 오디오 샘플 전체에 적용해본다. 원리를 확인한 뒤 실제 플러그인 단계에서 같은 처리 순서를 C++와 JUCE로 옮긴다.
